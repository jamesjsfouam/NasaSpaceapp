# Lista para la entrega

Los plazos y requisitos oficiales están en la *Project Submission Guide* y la
*Judging and Awards Guide* de Space Apps: revísalos, mandan sobre esta lista.

- [ ] Equipo registrado y reto elegido en el sitio de Space Apps
- [ ] Repositorio público con el código y licencia abierta
- [ ] README con: problema, solución, cómo ejecutarlo, datos de NASA usados
- [ ] Demo (presentación o video) con enlace público
- [ ] Lista de datos, herramientas y recursos utilizados, con sus fuentes
- [ ] Declarar el uso de herramientas de IA, si las hubo
- [ ] Sin claves ni datos de pacientes en el repositorio
- [ ] Página del proyecto completada antes de la hora límite local
